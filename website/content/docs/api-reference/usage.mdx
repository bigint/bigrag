---
title: Usage
description: Aggregate per-collection usage statistics.
---

```
GET /v1/admin/usage
```

Session-only. Returns the per-collection resource footprint over a trailing window — useful for quota enforcement, billing, and capacity planning.

## Query parameters

| Parameter | Type | Default | Notes |
|-----------|------|---------|-------|
| `window_days` | integer | `30` | Days of embedding/query history to aggregate |
| `collection` | string | — | Optional filter to a single collection name |

## Response

```json
{
  "window_days": 30,
  "totals": {
    "api_requests": 18231,
    "queries": 9122,
    "documents_uploaded": 482,
    "embedding_tokens": 1820432,
    "embedding_cost_usd_estimate": 0.36,
    "storage_bytes": 52428800
  },
  "by_collection": [
    {
      "collection": "knowledge_base",
      "documents": 15,
      "chunks": 482,
      "storage_bytes": 52428800,
      "queries": 1203,
      "embedding_tokens": 125000,
      "embedding_cost_usd_estimate": 0.025
    }
  ],
  "generated_at": "2026-04-12T10:22:00Z"
}
```

Cost estimates use public list prices for OpenAI / Cohere; self-hosted `openai_compatible` endpoints are reported as `0`.

## Common patterns

- **Billing join:** join `by_collection[].collection` onto your own `tenant_id ↔ collection_name` map and invoice. See [Multi-tenant SaaS](/docs/cookbook/multi-tenant-saas).
- **Quota alert:** poll with `window_days=1` and alert when a tenant's `embedding_tokens` exceeds their plan.
- **Capacity planning:** pair with [`GET /v1/stats`](/docs/api-reference/health#platform-stats) to watch trend + global health.
