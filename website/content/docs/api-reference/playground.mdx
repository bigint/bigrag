---
title: Playground
description: Session-only Studio playground generation endpoint.
---

Base path: `/v1/playground`

Session-only. Studio uses this endpoint to stream generated answers without exposing the saved OpenAI key to the browser. Save or replace the key through `/v1/auth/preferences` using `playground.openai_key`; preference responses only return `playground.has_openai_key`.

## Stream Chat

```
POST /v1/playground/chat
```

Streams an OpenAI chat completion as Server-Sent Events.

```json
{
  "model": "gpt-4o-mini",
  "temperature": 0.2,
  "messages": [
    { "role": "system", "content": "Use the supplied context." },
    { "role": "user", "content": "What changed in the policy?" }
  ]
}
```

SSE frames use this shape:

```text
data: {"delta":"partial text"}

data: [DONE]
```

If the upstream OpenAI request fails after streaming starts, the endpoint emits:

```text
data: {"error":"OpenAI error message"}
```
