---
title: Embedding Presets
description: Reusable embedding provider + model configurations.
---

Base path: `/v1/admin/embedding-presets`

Presets let you save an embedding provider, model, dimension, base URL, and API key once and reference them when creating collections. Collections linked with `embedding_preset_id` read the preset live, so preset updates affect those collections and invalidate their cached config.

Session-only. The `api_key` column is Fernet-encrypted at rest with `BIGRAG_MASTER_KEY` — see [Encryption at rest](/docs/deployment/encryption).

## List Presets

```
GET /v1/admin/embedding-presets?limit=100&offset=0
```

**Response** `200`:

```json
{
  "presets": [
    {
      "id": "a1…",
      "name": "OpenAI small",
      "provider": "openai",
      "model": "text-embedding-3-small",
      "base_url": null,
      "dimension": 1536,
      "has_api_key": true,
      "created_at": "2026-04-01T00:00:00Z",
      "updated_at": "2026-04-01T00:00:00Z"
    }
  ],
  "total": 1
}
```

The raw `api_key` is never returned; only `has_api_key` is surfaced.

## Create Preset

```
POST /v1/admin/embedding-presets
```

```json
{
  "name": "Voyage 3 large",
  "provider": "voyage",
  "model": "voyage-3-large",
  "dimension": 1024,
  "api_key": "pa-..."
}
```

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `name` | string | yes | Unique |
| `provider` | string | yes | `openai`, `openai_compatible`, `cohere`, or `voyage` |
| `model` | string | yes | Provider model name |
| `base_url` | string | no | Required for `openai_compatible`; optional override for OpenAI-compatible gateways |
| `dimension` | integer | yes | Must match the model |
| `api_key` | string | yes | Stored server-side |

**Response** `201`: preset without `api_key`.

## Update Preset

```
PATCH /v1/admin/embedding-presets/{preset_id}
```

Partial — any combination of `name`, `provider`, `model`, `base_url`, `dimension`, `api_key`. Updating credentials propagates immediately to every collection linked via `embedding_preset_id`; their cached config is invalidated as part of the request.

## Test Preset Credentials

```
POST /v1/admin/embedding-presets/test
POST /v1/admin/embedding-presets/{preset_id}/test
```

The first form tests plaintext form values before create/update:

```json
{
  "provider": "openai_compatible",
  "model": "text-embedding-3-small",
  "base_url": "https://gateway.example.com/v1",
  "api_key": "sk-..."
}
```

The saved-preset form tests the encrypted key already stored for an existing preset. Both return `{"status":"ok","message":"Embedding provider connection succeeded"}` on success.

## Delete Preset

```
DELETE /v1/admin/embedding-presets/{preset_id}
```

Removes the preset. Returns `409` when any collection still references it via `embedding_preset_id` — switch those collections to a per-collection key (or another preset) first.
