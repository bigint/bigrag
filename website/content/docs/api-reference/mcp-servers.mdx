Base path: `/v1/admin/mcp-servers` — Session-only (admin UI).

Each MCP server is an API key with extra metadata (`title`, `server_name`, optional `collection` scope). MCP keys are read/query-only by default with `collection:read`, `document:read`, and `query:read`. They reuse the same `ApiKey` row, auth, scope, and audit machinery as ordinary API keys — but `/v1/admin/api-keys` filters MCP-tagged keys out to keep that list clean.

A delete on the underlying API key cascades through. Generic API keys and MCP servers share a uniqueness constraint on `key_hash`.

<Accordions type="multiple">

<Accordion title="GET /v1/admin/mcp-servers — List MCP servers">

Returns only MCP-tagged keys owned by the calling admin.

```
GET /v1/admin/mcp-servers
```

**Response** `200`:

```json
{
  "servers": [
    {
      "id": "1e482…",
      "title": "Resumes RAG",
      "server_name": "resumes",
      "collection": "resumes",
      "key_prefix": "bigrag_sk_Ge0v",
      "last_used_at": "2026-04-25T05:21:09Z",
      "created_at": "2026-04-12T08:44:59Z",
      "updated_at": "2026-04-12T08:44:59Z"
    }
  ],
  "total": 1
}
```

</Accordion>

<Accordion title="POST /v1/admin/mcp-servers — Create MCP server">

Mints a fresh API key bound to the new server. The plaintext token is returned **once** in `api_key` — store it before the response leaves the wire.

```
POST /v1/admin/mcp-servers
```

**Request fields:**

| Field | Type | Required | Notes |
|-------|------|----------|-------|
| `title` | string | yes | 1–80 chars. Display name in the admin UI and the client's connector list. |
| `server_name` | string | yes | 1–60 chars. Lowercase alphanumeric and dashes (`^[a-z0-9][a-z0-9-]*$`). Used as the key under `mcpServers` in the client config; must be unique per owner. |
| `collection` | string | no | Pin the credential to a single collection. If set, the collection must exist. Omit or set to empty for a global key. |

**Response** `201`:

```json
{
  "id": "1e482…",
  "title": "Resumes RAG",
  "server_name": "resumes",
  "collection": "resumes",
  "key_prefix": "bigrag_sk_Ge0v",
  "last_used_at": null,
  "created_at": "2026-04-25T05:21:09Z",
  "updated_at": "2026-04-25T05:21:09Z",
  "api_key": "bigrag_sk_Ge0v..."
}
```

**Errors:** `409` if `server_name` already exists for this user. `400` if `collection` does not exist.

</Accordion>

<Accordion title="PATCH /v1/admin/mcp-servers/{server_id} — Update MCP server">

Edit `title`, `server_name`, and/or `collection`. Send only the fields you want to change.

```
PATCH /v1/admin/mcp-servers/{server_id}
```

| Field | Type | Notes |
|-------|------|-------|
| `title` | string | Optional |
| `server_name` | string | Optional. Same constraints as create; uniqueness re-checked. |
| `collection` | string | Optional. Empty string clears the scope; a name pins to that collection. |

**Response** `200`: same shape as the list entry above.

</Accordion>

<Accordion title="POST /v1/admin/mcp-servers/{server_id}/rotate — Rotate credential">

Mints a new API key for an existing server and invalidates the old one immediately. Use this if the previous URL leaked or was lost.

```
POST /v1/admin/mcp-servers/{server_id}/rotate
```

**Response** `200`: same shape as create — includes a one-shot `api_key`.

</Accordion>

<Accordion title="DELETE /v1/admin/mcp-servers/{server_id} — Delete MCP server">

Removes the server and its underlying API key. Existing connector URLs stop working on the next request.

```
DELETE /v1/admin/mcp-servers/{server_id}
```

**Response** `200`:

```json
{ "status": "ok", "message": "MCP server deleted" }
```

</Accordion>

</Accordions>
