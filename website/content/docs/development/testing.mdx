## Current status

The previous package-level unit tests, integration tests, end-to-end tests, and coverage suites have been removed from the backend, SDKs, and admin UI. The related coverage commands, local coverage reports, fake-provider test stack, and test-only Docker Compose workflow have also been removed.

Do not rely on removed package test runners, end-to-end runners, or coverage commands as required verification for this repository while this reset is in place.

## Local verification

Use lint, typecheck, build, and runtime smoke checks that match the code you changed:

```bash
pnpm lint
pnpm --filter @bigrag/docs build
pnpm --filter @bigrag/app build
pnpm --filter @bigrag/client typecheck
pnpm --filter @bigrag/client build
cd api && uv run ruff check . && uv run ruff format --check .
cd sdks/python && uv build
```

The docs package runs `fumadocs-mdx` before `next build`, so a clean checkout or container build generates `website/.source` before Turbopack resolves the docs source imports.

The admin app scripts generate and clean `app/src/routeTree.gen.ts` before Vite starts, before app builds, and before app typecheck. Vite code splitting reads that generated route tree but does not rewrite it during normal dev-server file watching.

## CI verification

CI currently keeps formatter, lint, typecheck, SDK build, docs build, and admin UI build. It does not run package-level test, coverage, end-to-end, or UI browser-test jobs.
