## Current status

The previous package-level unit and integration test suites have been removed from the backend, SDKs, and admin UI. The related coverage commands and local coverage reports have also been removed.

Do not rely on removed package test runners or coverage commands as required verification for this repository while this reset is in place. The maintained end-to-end suite is API and SDK only; UI end-to-end tests are not part of the current verification layer.

## Local verification

Use lint, typecheck, build, and runtime smoke checks that match the code you changed:

```bash
pnpm lint
pnpm --filter @bigrag/docs build
pnpm --filter @bigrag/app build
pnpm --filter @bigrag/client typecheck
pnpm --filter @bigrag/client build
cd api && uv run ruff check . && uv run ruff format --check .
cd sdks/python && uv build
cargo fmt --manifest-path sdks/rust/Cargo.toml --check
cargo check --manifest-path sdks/rust/Cargo.toml
```

The docs package runs `fumadocs-mdx` before `next build`, so a clean checkout or container build generates `website/.source` before Turbopack resolves the docs source imports.

The admin app scripts generate and clean `app/src/routeTree.gen.ts` before Vite starts, before app builds, and before app typecheck. Vite code splitting reads that generated route tree but does not rewrite it during normal dev-server file watching.

## CI verification

CI currently keeps formatter, lint, typecheck, SDK build, docs build, admin UI build, Rust formatting and compile checks, and the API/SDK end-to-end workflow. It does not run package-level test, coverage, or UI end-to-end jobs.

The E2E workflow uses the local fake OpenAI service only. There is no maintained real OpenAI smoke job.

## E2E

The `e2e/` workspace contains API pytest coverage, Python SDK contract tests, and TypeScript SDK Vitest coverage. It intentionally does not include Playwright or other UI browser tests.
