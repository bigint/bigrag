bigRAG reads configuration from a `bigrag.toml` file and/or environment variables. Environment variables take precedence over TOML values, and CLI flags passed to `python -m bigrag.main` override both. Logging is configured through TOML or CLI flags.

Auth is admin accounts + session cookies and minted `bigrag_sk_…` API keys — see [Authentication](/docs/api-reference/authentication).

## TOML configuration

Create a `bigrag.toml` file in the project root:

```toml
# Keys are flat and match `api/bigrag/config.py` field names.
env = "prod"                         # "dev" (default) or "prod"

host = "0.0.0.0"
port = 4000
workers = 1
log_level = "info"                   # debug, info, warning, error
log_format = "json"                  # text or json
cors_origins = ["https://app.example.com"]
trusted_proxies = ["10.0.0.0/8"]

database_url = "postgres://bigrag:bigrag@localhost:5432/bigrag?sslmode=disable"
db_pool_min = 5
db_pool_max = 50
migration_timeout_seconds = 60

qdrant_url = "http://localhost:6333"
qdrant_api_key = ""
qdrant_connect_timeout_seconds = 10
qdrant_required = false
qdrant_search_ef = 128

redis_url = "redis://localhost:6379/0"

master_key = ""                      # required in prod
master_key_previous = []             # old Fernet keys during rotation

session_expiry_hours = 168
session_cookie_name = "bigrag_session"
session_cookie_secure = true         # must be true in production
session_cookie_samesite = "lax"      # lax, strict, none
# session_cookie_domain = ".example.com"

embedding_provider = "openai"        # openai, openai_compatible, cohere, voyage
embedding_model = "text-embedding-3-small"
embedding_dimension = 1536
# embedding_base_url = "http://ollama:11434/v1"
# embedding_api_key = "sk-..."       # Optional server default; usually per collection
embedding_concurrency = 8

max_upload_size_mb = 64
max_batch_upload_size_mb = 128
ingestion_workers = 4
ingestion_batch_size = 128
conversion_timeout = 300

upload_dir = "./data/uploads"

webhook_delivery_timeout = 10
webhook_retry_delays = [10, 30, 90]
webhook_max_count = 50

queue_max_depth = 10000
```

## Environment variables

Runtime settings use the `BIGRAG_` prefix. Environment variables override TOML values.

### Server

| Variable | Description | Default |
|----------|-------------|---------|
| `BIGRAG_ENV` | `dev` or `prod`. Production mode refuses to start if CORS is `*`, cookies aren't `Secure`, or Postgres still uses the shipped default password | `dev` |
| `BIGRAG_PORT` | Server port | `4000` |
| `BIGRAG_HOST` | Bind address | `0.0.0.0` |
| `BIGRAG_WORKERS` | Uvicorn workers | `1` |
| `BIGRAG_CORS_ORIGINS` | Allowed CORS origins (JSON array; `["*"]` rejected in `prod`) | `[]` |
| `BIGRAG_TRUSTED_PROXIES` | Trusted reverse-proxy CIDRs as a JSON array. When the immediate client is trusted, bigRAG uses the rightmost untrusted `X-Forwarded-For` IP for audit and access logs. | `[]` |

### Infrastructure

| Variable | Description | Default |
|----------|-------------|---------|
| `BIGRAG_DATABASE_URL` | Postgres connection URL | `postgres://bigrag:bigrag@localhost:5432/bigrag?sslmode=disable` |
| `BIGRAG_MIGRATION_TIMEOUT_SECONDS` | Startup migration check timeout (`0` disables the timeout) | `60` |
| `BIGRAG_QDRANT_URL` | Qdrant connection URL | `http://localhost:6333` |
| `BIGRAG_QDRANT_API_KEY` | Optional Qdrant Cloud/API key | — |
| `BIGRAG_QDRANT_CONNECT_TIMEOUT_SECONDS` | Qdrant startup connection timeout (`0` disables the timeout) | `10` |
| `BIGRAG_QDRANT_REQUIRED` | Fail API startup if Qdrant cannot be reached | `false` |
| `BIGRAG_REDIS_URL` | Redis connection URL | `redis://localhost:6379/0` |
| `BIGRAG_DB_POOL_MIN` | Min Postgres pool size | `5` |
| `BIGRAG_DB_POOL_MAX` | Max Postgres pool size | `50` |

### Sessions & auth

| Variable | Description | Default |
|----------|-------------|---------|
| `BIGRAG_SESSION_EXPIRY_HOURS` | Session cookie lifetime | `168` (7 days) |
| `BIGRAG_SESSION_COOKIE_NAME` | Cookie name | `bigrag_session` |
| `BIGRAG_SESSION_COOKIE_SECURE` | Set `Secure` flag. Must be `true` in production | `false` |
| `BIGRAG_SESSION_COOKIE_SAMESITE` | `lax`, `strict`, or `none` | `lax` |
| `BIGRAG_SESSION_COOKIE_DOMAIN` | Optional cookie scope | — |
| `BIGRAG_MASTER_KEY` | Fernet key (32-byte urlsafe-base64) used to envelope-encrypt provider credentials stored in Postgres. Required in `prod`. See [Encryption at rest](/docs/deployment/encryption). | — |
| `BIGRAG_MASTER_KEY_PREVIOUS` | JSON array of old Fernet keys for staged credential-key rotation | `[]` |

Admins are created via [`POST /v1/auth/setup`](/docs/api-reference/authentication) and API keys are minted via [`POST /v1/admin/api-keys`](/docs/api-reference/api-keys).

### Embedding (server defaults)

Embedding provider, model, and key are normally configured per collection. These server-level defaults are used only when a collection is created without them (for example by the `/setup` flow or the first admin UI run).

| Variable | Description | Default |
|----------|-------------|---------|
| `BIGRAG_EMBEDDING_PROVIDER` | `openai`, `cohere`, `voyage`, or `openai_compatible` | `openai` |
| `BIGRAG_EMBEDDING_MODEL` | Default model name | `text-embedding-3-small` |
| `BIGRAG_EMBEDDING_DIMENSION` | Default vector dimension | `1536` |
| `BIGRAG_EMBEDDING_BASE_URL` | Base URL for OpenAI-compatible embedding endpoints | — |
| `BIGRAG_EMBEDDING_API_KEY` | Default provider API key | — |

### Ingestion

| Variable | Description | Default |
|----------|-------------|---------|
| `BIGRAG_MAX_UPLOAD_SIZE_MB` | Max upload file size in MB | `1024` |
| `BIGRAG_INGESTION_WORKERS` | Background processing workers | `4` |
| `BIGRAG_INGESTION_BATCH_SIZE` | Vectors per embedding batch | `128` |
| `BIGRAG_CONVERSION_TIMEOUT` | Docling conversion timeout (seconds) | `300` |

### Storage

| Variable | Description | Default |
|----------|-------------|---------|
| `BIGRAG_UPLOAD_DIR` | Local upload directory | `./data/uploads` |

### Webhooks

| Variable | Description | Default |
|----------|-------------|---------|
| `BIGRAG_WEBHOOK_DELIVERY_TIMEOUT` | Per-request HTTP timeout (seconds) | `10` |
| `BIGRAG_WEBHOOK_RETRY_DELAYS` | Exponential retry delays, seconds (JSON array) | `[10, 30, 90]` |
| `BIGRAG_WEBHOOK_CACHE_TTL` | Webhook config cache TTL (seconds) | `60` |
| `BIGRAG_WEBHOOK_MAX_COUNT` | Max webhooks per instance | `50` |

### Tuning

| Variable | Description | Default |
|----------|-------------|---------|
| `BIGRAG_EMBEDDING_CONCURRENCY` | Max concurrent embedding requests | `8` |
| `BIGRAG_QDRANT_SEARCH_EF` | Optional Qdrant HNSW `ef` search value (higher recall, higher latency) | — |
| `BIGRAG_COLLECTION_CACHE_TTL` | Collection metadata cache TTL (seconds) | `30` |
| `BIGRAG_AUTH_PRINCIPAL_CACHE_TTL` | Session/API-key principal cache TTL (seconds) | `60` |
| `BIGRAG_QUERY_EMBEDDING_CACHE_TTL` | Query embedding cache TTL (seconds) | `3600` |
| `BIGRAG_QUERY_RESULT_CACHE_TTL` | Exact query result cache TTL (seconds) | `30` |
| `BIGRAG_QUEUE_MAX_DEPTH` | Max pending jobs in the ingestion queue | `10000` |

## CLI flags

`python -m bigrag.main` accepts overrides that take precedence over TOML and env:

```
--config PATH            Path to bigrag.toml (default: bigrag.toml)
--host HOST              Override server host
--port PORT              Override server port
--database-url URL       Override Postgres URL
--qdrant-url URL         Override Qdrant URL
--redis-url URL          Override Redis URL
--log-level LEVEL        Override log level
--log-format FORMAT      text | json
```

<Callout type="info">
Embedding provider, model, dimension, chunk size, and chunk overlap are normally configured **per collection** via the API. The server-level values above are only used as defaults when a collection is created without them.
</Callout>
