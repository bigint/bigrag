Follow these steps to go from zero to searching your documents.

<Steps>
<Step>
### Start bigRAG

```bash
docker compose up -d
```

Wait for all services to be healthy, then verify:

```bash
curl http://localhost:6100/health
```
</Step>

<Step>
### Configure environment

Set your embedding provider key and (optionally) an API secret:

```bash
export OPENAI_API_KEY="sk-..."
export BIGRAG_API_SECRET="your-api-secret"
export BASE="http://localhost:6100"
```

<Callout type="warn">
  An embedding API key (OpenAI or Cohere) is required to process documents. You can set it globally via `BIGRAG_EMBEDDING_API_KEY` or per-collection when creating one.
</Callout>
</Step>

<Step>
### Create a collection

A collection groups documents that share the same embedding configuration.

<Tabs items={["curl", "TypeScript SDK"]}>
<Tab value="curl">
```bash
curl -X POST $BASE/v1/collections \
  -H "Authorization: Bearer $BIGRAG_API_SECRET" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "knowledge_base",
    "description": "Company knowledge base",
    "embedding_api_key": "'"$OPENAI_API_KEY"'",
    "chunk_size": 512,
    "chunk_overlap": 50
  }'
```
</Tab>
<Tab value="TypeScript SDK">
```typescript
import { BigRAG } from "@bigrag/client";

const client = new BigRAG({
  apiSecret: "your-api-secret",
  baseUrl: "http://localhost:6100",
});

const collection = await client.createCollection({
  name: "knowledge_base",
  description: "Company knowledge base",
  embedding_api_key: process.env.OPENAI_API_KEY,
  chunk_size: 512,
  chunk_overlap: 50,
});
```
</Tab>
</Tabs>
</Step>

<Step>
### Upload a document

<Tabs items={["curl", "TypeScript SDK"]}>
<Tab value="curl">
```bash
curl -X POST $BASE/v1/collections/knowledge_base/documents \
  -H "Authorization: Bearer $BIGRAG_API_SECRET" \
  -F "file=@handbook.pdf" \
  -F 'metadata={"department": "engineering"}'
```
</Tab>
<Tab value="TypeScript SDK">
```typescript
const doc = await client.uploadDocument(
  "knowledge_base",
  new File([buffer], "handbook.pdf"),
  { department: "engineering" }
);
```
</Tab>
</Tabs>

The document starts as `pending` and transitions to `processing` then `ready`.
</Step>

<Step>
### Check document status

<Tabs items={["curl", "TypeScript SDK"]}>
<Tab value="curl">
```bash
curl $BASE/v1/collections/knowledge_base/documents \
  -H "Authorization: Bearer $BIGRAG_API_SECRET"
```
</Tab>
<Tab value="TypeScript SDK">
```typescript
// Stream real-time progress
for await (const event of client.streamDocumentProgress("knowledge_base", doc.id)) {
  console.log(`${event.step}: ${event.progress}%`);
  if (event.status === "complete") break;
}
```
</Tab>
</Tabs>
</Step>

<Step>
### Query the collection

Once documents are `ready`, you can search:

<Tabs items={["curl", "TypeScript SDK"]}>
<Tab value="curl">
```bash
curl -X POST $BASE/v1/collections/knowledge_base/query \
  -H "Authorization: Bearer $BIGRAG_API_SECRET" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "What is the PTO policy?",
    "top_k": 5
  }'
```
</Tab>
<Tab value="TypeScript SDK">
```typescript
const { results } = await client.query("knowledge_base", {
  query: "What is the PTO policy?",
  top_k: 5,
});

for (const result of results) {
  console.log(`[${result.score.toFixed(3)}] ${result.text}`);
}
```
</Tab>
</Tabs>
</Step>
</Steps>
