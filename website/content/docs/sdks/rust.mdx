## Installation

Add `bigrag` to your `Cargo.toml`:

```toml
[dependencies]
bigrag = "0.1"
tokio = { version = "1", features = ["full"] }
```

<Callout type="info">
  Requires Rust 1.75+ and Tokio async runtime.
</Callout>

## Quick Start

```rust
use bigrag::BigRag;
use bigrag::types::{CreateCollectionBody, QueryBody};

#[tokio::main]
async fn main() -> Result<(), bigrag::BigRagError> {
    let client = BigRag::new("http://localhost:6100", "your-api-key");

    // Create a collection
    let col = client.collections().create(CreateCollectionBody {
        name: "my-docs".into(),
        ..Default::default()
    }).await?;

    // Upload a document
    let doc = client.documents().upload("my-docs", "/path/to/file.pdf", None).await?;

    // Query
    let results = client.queries().query("my-docs", QueryBody {
        query: "How does it work?".into(),
        ..Default::default()
    }).await?;

    for r in &results.results {
        println!("[{:.2}] {}", r.score, r.text);
    }

    Ok(())
}
```

## Configuration

| Option | Default | Description |
|--------|---------|-------------|
| `base_url` | `http://localhost:6100` | bigRAG API URL |
| `api_key` | `BIGRAG_API_KEY` env var | API key for authentication |
| `timeout` | `120s` | Request timeout |
| `max_retries` | `2` | Max retries for transient errors |

```rust
use std::time::Duration;
use bigrag::BigRag;

// From environment variables
let client = BigRag::from_env()?;

// Builder pattern
let client = BigRag::builder()
    .base_url("https://bigrag.example.com")
    .api_key("sk-...")
    .timeout(Duration::from_secs(60))
    .max_retries(3)
    .build()?;
```

## Collections

```rust
use bigrag::types::*;

// List
let cols = client.collections().list(None).await?;

// Create
let col = client.collections().create(CreateCollectionBody {
    name: "docs".into(),
    embedding_provider: Some("openai".into()),
    ..Default::default()
}).await?;

// Get
let col = client.collections().get("docs").await?;

// Update
client.collections().update("docs", UpdateCollectionBody {
    description: Some("Updated".into()),
    ..Default::default()
}).await?;

// Stats
let stats = client.collections().stats("docs").await?;

// Truncate (delete all documents, keep the collection)
client.collections().truncate("docs").await?;

// Delete
client.collections().delete("docs").await?;
```

## Documents

```rust
// Upload a file
let doc = client.documents().upload("docs", "/path/to/file.pdf", None).await?;

// Upload with metadata
let meta = serde_json::json!({"department": "engineering"});
let doc = client.documents().upload("docs", "/path/to/file.pdf", Some(meta)).await?;

// Upload from bytes
let doc = client.documents().upload("docs", (pdf_bytes, "report.pdf"), None).await?;

// Batch upload
let files = vec![
    FileInput::from("/path/to/a.pdf"),
    FileInput::from("/path/to/b.docx"),
];
let docs = client.documents().batch_upload("docs", files, None).await?;

// List documents
let docs = client.documents().list("docs", None).await?;

// Get document chunks
let chunks = client.documents().get_chunks("docs", "doc-id").await?;

// Reprocess
client.documents().reprocess("docs", "doc-id").await?;

// Get a single document
let doc = client.documents().get("docs", "doc-id").await?;

// Delete a document
client.documents().delete("docs", "doc-id").await?;

// Get file download URL
let url = client.documents().get_file_url("docs", "doc-id").await?;

// Global document access (without collection scope)
let doc = client.documents().get_by_id("doc-id").await?;
let chunks = client.documents().get_chunks_by_id("doc-id").await?;

// Batch operations
let statuses = client.documents().batch_get_status("docs", &["id1", "id2"]).await?;
let docs = client.documents().batch_get("docs", &["id1", "id2"]).await?;
let result = client.documents().batch_delete("docs", &["id1", "id2"]).await?;

// S3 Ingestion
let resp = client.documents().ingest_s3("docs", S3IngestBody {
    bucket: "my-bucket".into(),
    prefix: Some("documents/".into()),
    ..Default::default()
}).await?;

// S3 job management
let jobs = client.documents().list_s3_jobs("docs").await?;
client.documents().resync_s3_job("docs", "job-id").await?;
client.documents().delete_s3_job("docs", "job-id").await?;

// Stream batch processing progress
use futures_util::StreamExt;
let mut stream = client.documents().stream_batch_progress("docs", &["id1", "id2"]).await?;
while let Some(event) = stream.next().await {
    let event = event?;
    println!("[{}/{}] {} failed", event.completed, event.total, event.failed);
}
```

File uploads accept `&str` / `String` paths, `Vec<u8>` bytes with a name tuple, `PathBuf`, or a `FileInput` enum value directly.

## Query & Search

```rust
use bigrag::types::*;

// Single collection query
let results = client.queries().query("docs", QueryBody {
    query: "search terms".into(),
    top_k: Some(5),
    search_mode: Some(SearchMode::Hybrid),
    ..Default::default()
}).await?;

// Multi-collection query
let results = client.queries().multi_query(MultiQueryBody {
    query: "search terms".into(),
    collections: vec!["docs".into(), "notes".into()],
    top_k: Some(10),
    ..Default::default()
}).await?;

// Batch queries
let results = client.queries().batch_query(BatchQueryBody {
    queries: vec![
        BatchQueryItem { collection: "docs".into(), query: "first query".into(), ..Default::default() },
        BatchQueryItem { collection: "docs".into(), query: "second query".into(), ..Default::default() },
    ],
}).await?;
```

## Scoped Collection Client

Use `client.collection(name)` to get a scoped client that omits the collection parameter:

```rust
let col = client.collection("my-docs");

// All methods are scoped — no need to pass the collection name
col.upload("/path/to/file.pdf", None).await?;
let docs = col.list_documents(None).await?;
let results = col.query(QueryBody { query: "search".into(), ..Default::default() }).await?;
let stats = col.stats().await?;
let analytics = col.analytics().await?;

// Batch operations
let files = vec![FileInput::from("/path/to/a.pdf"), FileInput::from("/path/to/b.pdf")];
let batch = col.batch_upload(files, None).await?;
let statuses = col.batch_get_status(&["id1", "id2"]).await?;
let batch_docs = col.batch_get(&["id1", "id2"]).await?;
col.batch_delete(&["id1", "id2"]).await?;

// S3 ingestion
col.ingest_s3(S3IngestBody { bucket: "my-bucket".into(), ..Default::default() }).await?;
let jobs = col.list_s3_jobs().await?;
col.resync_s3_job("job-id").await?;
col.delete_s3_job("job-id").await?;

// SSE streaming
let mut stream = col.stream_events().await?;
while let Some(event) = stream.next().await {
    println!("Event: {:?}", event?);
}
```

## Webhooks

```rust
use bigrag::types::*;

// Create
let resp = client.webhooks().create(CreateWebhookBody {
    url: "https://example.com/webhook".into(),
    events: vec!["document.ready".into()],
    collections: None, // all collections
    description: Some("Notify on doc ready".into()),
}).await?;
println!("Secret: {}", resp.secret); // save this!

// List
let hooks = client.webhooks().list().await?;

// Get
let hook = client.webhooks().get("webhook-id").await?;

// Update
client.webhooks().update("webhook-id", UpdateWebhookBody {
    active: Some(false),
    ..Default::default()
}).await?;

// Delete
client.webhooks().delete("webhook-id").await?;

// List deliveries
let deliveries = client.webhooks().list_deliveries("webhook-id", None).await?;
// with pagination
let deliveries = client.webhooks().list_deliveries("webhook-id", Some(ListDeliveriesOptions {
    limit: Some(20),
    offset: Some(0),
})).await?;

// Test
let test = client.webhooks().test("webhook-id").await?;
```

## Error Handling

All methods return `Result<T, BigRagError>`. Use pattern matching for specific errors:

```rust
use bigrag::BigRagError;

match client.collections().get("my-col").await {
    Ok(col) => println!("Found: {}", col.name),
    Err(BigRagError::NotFound { .. }) => println!("Collection not found"),
    Err(BigRagError::Authentication { .. }) => println!("Invalid API key"),
    Err(e) if e.is_retryable() => println!("Transient error, retry later"),
    Err(e) => eprintln!("Error: {e}"),
}
```

| Error Variant | HTTP Status | Retryable |
|---------------|-------------|-----------|
| `BadRequest` | 400 | No |
| `Authentication` | 401/403 | No |
| `NotFound` | 404 | No |
| `Conflict` | 409 | No |
| `RateLimited` | 429 | Yes |
| `ServerError` | 5xx | Yes |
| `Timeout` | — | Yes |
| `Connection` | — | Yes |

## Retry Behavior

The SDK automatically retries on transient errors (429, 5xx, timeouts, connection failures) with exponential backoff:

- **Backoff**: 500ms, 1s, 2s, 4s (capped)
- **Default retries**: 2
- **Not retried**: File uploads, SSE streams, 4xx client errors
