## Installation

```bash
pip install bigrag
```

## Quick Start

```python
from bigrag import BigRAG

client = BigRAG(
    api_secret="your-api-secret",
    base_url="http://localhost:6100",
)

# Create a collection
collection = client.create_collection(
    name="knowledge_base",
    description="Company docs",
    chunk_size=512,
)

# Upload a document
doc = client.upload_document("knowledge_base", "handbook.pdf")

# Query
results = client.query("knowledge_base", query="What is the PTO policy?", top_k=5)
for result in results:
    print(f"[{result.score:.3f}] {result.text}")
```

## Configuration

| Option | Default | Description |
|--------|---------|-------------|
| `api_secret` | `BIGRAG_API_SECRET` env var | Shared API secret |
| `base_url` | `http://localhost:6100` | bigRAG server URL |
| `timeout` | `120` | Request timeout in seconds |
| `max_retries` | `2` | Max retries on 5xx and network errors |

## Collections

```python
client.list_collections()
client.create_collection(name, description=None, embedding_provider=None, ...)
client.get_collection(name)
client.update_collection(name, description=None, metadata=None)
client.delete_collection(name)
```

## Documents

```python
client.upload_document(collection, file_path, metadata=None)
client.list_documents(collection, status=None, limit=100, offset=0)
client.get_document(collection, document_id)
client.delete_document(collection, document_id)
client.reprocess_document(collection, document_id)
client.get_document_chunks(collection, document_id)
```

## Query

```python
client.query(collection, query, top_k=10, filters=None, min_score=None, search_mode=None)
client.multi_query(query, collections, top_k=10)
client.batch_query(queries)
```

## Error Handling

```python
from bigrag import BigRAG, NotFoundError, AuthenticationError, APIError

try:
    client.get_collection("missing")
except NotFoundError:
    print("Collection not found")
except AuthenticationError:
    print("Invalid API secret")
except APIError as e:
    print(f"API error: {e.status} {e.message}")
```
