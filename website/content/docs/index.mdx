bigRAG is an open-source RAG (Retrieval-Augmented Generation) platform. It provides a complete pipeline for document ingestion, chunking, embedding, and vector search — behind a REST API, a TypeScript/Python/Rust SDK, and a Studio admin UI.

## Key Features

- **End-to-end RAG pipeline** — upload documents, auto-chunk, embed, search, and rerank in one platform
- **Any document format** — PDF, DOCX, PPTX, XLSX, HTML, Markdown, CSV/TSV/XML/JSON, and scanned images (OCR) via [Docling](https://github.com/DS4SD/docling)
- **Any embedding model** — OpenAI, Cohere, or `openai_compatible` gateways (Ollama, vLLM, TEI, LiteLLM, Azure, Bedrock) configured per collection
- **Three search modes** plus HyDE, MMR diversity, metadata facets, and a semantic result cache
- **Milvus vector database** — tenant-aware partitions, IVF_FLAT or HNSW indexes
- **First-class auth** — admin accounts, session cookies, `bigrag_sk_…` API keys with scopes and rate limits, full audit log, and GDPR cascade-delete
- **Operational features** — S3 bulk ingestion, webhooks with HMAC signatures, per-collection PII redaction and content moderation, an evaluation runner, and per-collection query analytics
- **Studio admin UI** — first-run setup, collection browser, query playground, API-key minter, webhook manager
- **Self-hostable** — Docker Compose, no external dependencies
- **MIT licensed** — run it anywhere, forever free
